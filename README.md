# Presentación ejecutiva CRUM Morelia

Proyecto web estático, navegable y responsivo para presentar una propuesta de transformación digital del CRUM Morelia. No requiere backend y puede publicarse en GitHub Pages.

## Ejecutar localmente
Abre `index.html` en un navegador moderno. Para una experiencia más consistente, sirve la carpeta con un servidor estático local (por ejemplo, la extensión Live Server de VS Code).

## Navegación
- Flechas izquierda/derecha, Page Up/Page Down y barra espaciadora.
- Botones inferior anterior/siguiente.
- Menú de índice en la barra superior.
- Botón de pantalla completa o tecla `F`.
- Deslizar a izquierda/derecha en pantallas táctiles.
- Calculadora editable en la diapositiva 13.

## Publicar en GitHub Pages
1. Crea un repositorio y carga el contenido completo de esta carpeta.
2. En Settings → Pages, selecciona Deploy from a branch.
3. Selecciona la rama principal y la carpeta `/ (root)`.
4. Guarda y espera la publicación. La página se servirá desde `index.html`.

## Identidad visual
Se incorporan referencias gráficas proporcionadas de ADDV. La interfaz usa una aproximación digital de la paleta observada: azul profundo, azul eléctrico/cian y fondos blancos; tipografía Lato con alternativas sans-serif. El logotipo se representa tipográficamente en esta maqueta, no como archivo vectorial oficial.

## Alcance y advertencias
- Los datos operativos mostrados se identifican como corte documental al 5 de febrero de 2026.
- Los datos de demostración de la interfaz conceptual no deben interpretarse como un tablero productivo ni como monitoreo en tiempo real.
- Los porcentajes decorativos de costo/impacto no son métricas del CRUM.
- La calculadora usa valores iniciales ilustrativos editables; no constituyen salarios, ahorros, inversión cotizada ni promesa de ROI.
- La estructura de módulos es una propuesta conceptual que requiere validación institucional.
- Los archivos de identidad incluidos en `assets/branding/` son las imágenes de referencia recibidas.

## Archivos
- `index.html`: presentación de 18 diapositivas.
- `css/styles.css`: identidad visual y diseño responsivo.
- `js/presentation.js`: navegación, índice, pantalla completa y gestos.
- `js/calculator.js`: calculadora de costo-beneficio.
- `assets/branding/`: referencias visuales ADDV proporcionadas.
- `INFORME_ANALISIS.md`: diagnóstico documental y supuestos.
